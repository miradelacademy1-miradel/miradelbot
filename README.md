# Miradel Academy — Mini-CRM

## Localda ishga tushirish
1. Node.js 20.6 yoki yangiroq bo'lsin (`node -v` bilan tekshiring).
2. `.env.example` faylidan nusxa olib `.env` nomi bilan saqlang va to'ldiring.
3. Terminalda shu papkada:
   npm install
   npm run dev
4. Brauzerda http://localhost:3000 oching. Admin: .env dagi ADMIN_PHONE va ADMIN_PASSWORD.

## PostgreSQL (ikki yo'ldan biri)
- Kompyuteringizga PostgreSQL o'rnating, `miradel` bazasini yarating va DATABASE_URL ni shunga moslang.
- Yoki Railway'da PostgreSQL oching va uning tashqi (public) DATABASE_URL ini .env ga qo'ying.
